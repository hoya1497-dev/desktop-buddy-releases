# Desktop Buddy 🐱🏠

화면 위를 돌아다니는 작은 도트 고양이. 집을 꾸미고 밥을 주며 키우고, **데스크톱 코드**로 친구 집에 놀러 가서 같이 대화해요.

## 실행하기

[Node.js](https://nodejs.org) 18 이상이 필요해요.

```bash
cd desktop-pet
npm install
npm run server   # 터미널 1: 서버 (같은 컴퓨터에서 테스트할 때)
npm start        # 터미널 2: 앱
```

처음 실행하면 로그인 창이 떠요. **처음이에요**에서 가입하면 바꿀 수 없는 8자리 데스크톱 코드(예: `K7QM2XPA`)가 생겨요.

- **자동 로그인**: 로그인할 때 체크하면 다음부터는 창 없이 바로 접속돼요.
- **자동 실행**: 체크하면 컴퓨터를 켤 때 같이 켜져요.
  - Windows는 `npm start`로 실행해도 동작해요.
  - macOS는 `npm run dist`로 설치 파일을 만들어 설치해야 동작해요.

## 베타 테스트 (내 컴퓨터에서 먼저 시험하기)

```
npm run server     # 테스트 서버 (진짜 서버와 따로)
npm run beta       # 베타 앱 1 → ws://localhost:8787
npm run beta2      # 베타 앱 2 (두 번째 계정, 같이 켤 수 있음)
npm run admin -- give test1 5000   # 테스트 서버에 코인 넣기
npm run beta-real  # 진짜 서버에 붙는 개발용 앱
```

개발용 앱은 설치한 앱과 다른 폴더(`Desktop Buddy Dev …`)에 설정과 자동 로그인을 저장해요.

## 숨겨진 아이콘(트레이)의 집

작업 표시줄 오른쪽 숨겨진 아이콘(맥은 메뉴 막대)에 🏠 집 아이콘이 생겨요.

- **클릭**: 집 열기
- **우클릭**: 집 열기 / 방 나가기(혼자 놀기) / 캐릭터 불러오기 / 설정 / 로그아웃 / 종료

## 집

1층과 2층으로 된 복층 집이에요. 사다리로 오르내리고, 기본으로 1층에 컴퓨터, 2층에 침대가 있어요.

| 기능 | 방법 |
|---|---|
| 꾸미기 | **🛒 상점**에서 가구·인형·창문·벽지 사기 → **🎒 가방**에서 1층/2층 골라 놓기 → **✏️ 꾸미기**에서 끌어서 옮기기 |
| 돌리기 | 꾸미기에서 가구를 고른 뒤 아래 막대로 0~359° (⟲ ⟳ 15°씩, 마우스 휠도 돼요). ↔ 뒤집기, 🎒 넣기 |
| 벽지·바닥 | 1층과 2층에 따로 발라요. 실내 방 6종, 초원(낮/밤), 옥상(낮/밤하늘) |
| 불 | **💡 불 끄기/켜기** (집주인만). 끄면 실내가 어두워지고 스탠드·TV·트리·어항·창문 주변만 은은하게 밝아요 |
| 키우기 | **🍖 밥**에서 먹이 주기 → 배부름·기분·경험치 상승. 가끔 침대에 가서 자요 |
| 캐릭터 | 클릭하면 쓰다듬기, 끌면 옮기기(놓은 곳에서 가까운 층에 내려앉아요), 바닥을 클릭하면 그리로 걸어가요 |
| 화면 모드 | 오른쪽 위 🖥️/☀️/🌙 버튼으로 컴퓨터 설정 · 화이트 · 다크를 바꿔요 |
| 오른쪽 패널 | **패널 닫기 ▶** 버튼(또는 Ctrl+B)으로 접고 펴요. 패널 왼쪽 경계선을 끌면 넓이를 바꿀 수 있고, 두 번 누르면 접혀요. 이 컴퓨터에 기억돼요 |

가구는 모두 직접 찍은 도트 그림이에요(26종).

## 아이디와 닉네임

- **아이디**: 로그인용이라 바꿀 수 없어요. 캐릭터 이름표의 닉네임 아래에 `@아이디`로 작게 보여요.
- **닉네임**: 친구들에게 보이는 이름이에요. 가입할 때 정하고, 설정에서 언제든 바꿀 수 있어요.
- 집주인에게는 누가 들어왔는지 `닉네임(@아이디)`로 알림이 떠요.

## 아이디 바꾸기 (0.9)

설정 창 → **계정** 탭 → **아이디 바꾸기**에서 지금 아이디 · 비밀번호 · 새 아이디를 넣으면 바뀌어요.
- 코인 · 집 · 친구 · 물고기 · 펫 · 데스크톱 코드는 그대로예요. 자동 로그인도 풀리지 않아요.
- 24시간에 한 번 바꿀 수 있어요 (`catalog.js`의 `limits.renameHours`). 친구들에게는 "아이디가 바뀌었어요" 알림이 가요.
- 옛 아이디는 7일 동안 다른 사람이 가입하거나 가져갈 수 없어요. 그 사이엔 본인만 되돌릴 수 있어요.

## 0.13.9 새 기능

- **🖥️ 바탕화면 버디는 다시 각자 따로:** 0.13.8에서 바탕화면 버디 위치를 모두에게 똑같이 맞췄더니 친구 버디를 옮길 때 자꾸 제자리로 돌아가는 문제가 있었어요. 이제 **집 안에서만** 모두의 화면에서 같은 자리에 보이고, 바탕화면 버디는 각자 화면에서 따로 돌아다녀요. 친구 버디도 마음대로 옮길 수 있어요.
- **👉 콕 찌르면 모두에게 폴짝:** 친구를 콕 찌르면 찌른 나 · 찔린 친구 · 같은 방 모두의 화면에서 친구 버디가 똑같이 크게 튀어오르고 병아리 콕 그림이 떠요.
- **🎣 낚싯대 살짝 아래로:** 낚시터에서 낚싯대가 캐릭터보다 너무 위에 있어서 조금 내렸어요.
- **🔑 비밀번호 재설정 (관리자):** 비밀번호를 까먹은 친구는 운영자가 `npm run admin -- resetpw 아이디 [새비밀번호]`로 새 비밀번호를 정해 줄 수 있어요. 새 비밀번호를 안 넣으면 헷갈리지 않는 10자 임시 비밀번호를 만들어 보여줘요. 바꾸면 그 친구는 모든 기기에서 로그아웃되고, 틀려서 잠긴 것도 풀려요. 로그인에 실패하면 "비밀번호를 까먹었으면 운영자에게 말해 주세요"라고 안내해요.
- **👥 가입한 사람 보기 (관리자):** `npm run admin -- users`로 가입한 사람 전부(가입일 · 마지막 접속 · 레벨 · 코인 · 친구 수), `npm run admin -- user 아이디`(닉네임도 돼요)로 한 사람을 자세히(데스크톱 코드 · 친구 목록 · 로그인된 기기) 볼 수 있어요. 비밀번호는 안전하게 암호처럼 저장돼서 운영자도 볼 수 없어요.

## 0.13.8 새 기능

- **🛠️ 화면 깜빡임 · 가구 투명해지는 버그 수정:** 집 화면과 낚시터/아쿠아리움 화면을 그리는 반복 루프에 그림 오류가 나면 전체가 멈춰버리는 문제가 있었어요(그래서 한 번 깜빡이면 가구 · 물고기 · 펫이 계속 투명하게 보였어요). 오류가 나도 루프가 멈추지 않고 계속 그리게 고쳤어요. 앱만 바뀌어요.
- **🎣 낚싯대 크기 축소:** 낚시 장면에서 낚싯대가 너무 커 보여서 살짝 줄였어요.
- **🖥️ 바탕화면/집 버디 위치 동기화:** 돌아다니는 버디와 집 안 캐릭터가 이제 모든 사람 화면에서 같은 자리에 보여요(이전엔 각자 화면에서 따로 움직였어요). 앉은 상태도 다른 사람 화면에 그대로 보여요.
- **🪟 바탕화면 버디, 다른 창 위로 안 올라감:** 이제 바탕화면을 돌아다니는 버디는 바닥만 걸어다녀요.
- **💌 그림 이모티콘:** 집 채팅창에 그림 이모티콘 버튼(햄스터 안녕 · 펭귄 잘가 · 판다 잘자 · 여우 굿 · 고슴도치 싫어 · 유니콘 좋아 · 앵무새 응원)이 생겼어요. 누르면 그 그림이 캐릭터 머리 위에 크게 떠올라요. 친구를 콕 찌르면 병아리 그림이 떠요. 다른 사람 화면에서도 똑같이 보여요.
- **🎵 레코드 가구 다시 그리기:** 레코드 플레이어를 턴테이블 · 톤암 · 레코드판 무늬까지 더 자세하게 다시 그렸어요.
- **🍷 와인바 가구 추가:** 분위기를 내는 와인 랙 · 와인 바 카운터 · 바 스툴이 새로 생겼어요. 불을 끄면 와인 바 카운터가 은은하게 빛나요.

## 0.13.7 새 기능

- **🐟 물고기 도트 다시 그리기:** 물고기 · 쓰레기 66종을 더 자세하게 다시 그렸어요. 몸통에 명암과 반짝임이 생기고, 꼬리는 갈라지고, 지느러미에 결이 보여요. 테두리는 물고기 색을 진하게 한 색이라 덜 딱딱해 보여요. 그림 끝이 잘리지 않게 사방에 한 칸씩 여유를 두었어요. 문어 · 크라켄 · 새우는 새로 찍었고, 금붕어 · 구피 · 베타 꼬리는 꽉 찬 부채꼬리가 됐어요. 물고기 종류 · 확률 · 가격은 그대로예요 (앱만 바뀌어요).

- **🆕 새 가구:** 동그란 러그(220) · 줄무늬 러그(220) · 낮은 TV장(350, TV를 위에 올려요). 러그는 다른 가구 밑에 깔려요.
- **📐 꾸미기 격자:** 꾸미기 모드 안내줄에서 4px · 2px · 1px · 없음을 골라요. 끌면 격자에 맞춰 붙고, 방향키로 한 칸씩(Shift는 4칸) 옮겨요. 고른 격자는 이 컴퓨터에 저장돼요.
- **🎒 가방 정리:** 가방 → 가구에서 전부 방에 놓은 가구는 안 보여요. 방에서 다시 넣으면 돌아와요. 각 칸에 남은 개수와 방에 놓은 개수가 같이 보여요.

## 0.13.5 새 기능

- **🎨 낚시터 배경:** 낚시 탭 맨 위에서 시간(🌅 아침 · ☀️ 낮 · 🌇 저녁 · 🌙 밤)과 계절(🌸 봄 · 🌿 여름 · 🍁 가을 · ❄️ 겨울)을 골라요. 16가지 조합에 눈 · 꽃잎 · 낙엽 · 반딧불이 날려요. '자동'이면 실제 시간과 달을 따라가요. 고른 배경은 이 컴퓨터에만 저장되고 나한테만 보여요 (친구는 자기가 고른 배경으로 봐요).
- **💬 낚시하면서 채팅:** 낚시 탭 아래에 채팅 칸이 생겼어요. 채팅 탭과 같은 대화가 보이고, 친 말은 낚시터 캐릭터 머리 위에 말풍선으로 5초 떠요.
- **✨ 물고기 자랑:** 낚시 탭의 '최근에 낚은 것'에서 물고기를 누르면 머리 위로 번쩍 들어 4초 동안 자랑해요. 같은 낚시터에 있는 친구에게도 보여요 (도감에 있는 물고기만). 자세히 보기는 칸 오른쪽 위 📖.
- **☑️ 골라서 팔기:** 가방 → 물고기 → ☑️ 골라서 팔기. 물고기를 누르면 그 종류를 전부 고르고 −/+로 개수를 조절해요. 아래 막대에서 '팔기'를 두 번 누르면 한 번에 팔려요. '중복만 팔기'도 이제 같은 화면에 미리 골라 둔 채로 열려요.
- **🐛 버그 수정:** 물고기를 판 뒤 채팅 입력칸이 먹통이 되던 문제를 고쳤어요 (확인창이 닫힌 뒤 창 포커스를 다시 잡아요. 모든 확인창에 적용).
- **💡 조명 가구 5종:** 벽등(260) · 펜던트 조명(320) · 줄전구(300)는 벽에 걸고, 버섯 무드등(220) · 캔들 세트(180)는 바닥에 놔요. 불을 끄면 은은하게 빛나요.
- **🌙 층마다 불 켜고 끄기:** 아래 도구 막대의 '2층 · 1층' 버튼으로 따로 켜고 꺼요. 예전 앱은 두 층이 다 꺼져 있을 때만 '꺼짐'으로 보여요.
- **👥 친구의 친구 초대:** 친구 집에 놀러 가 있을 때 친구 목록의 '📨 이 집으로'로 내 친구를 초대해요. 초대받은 사람이 수락하면 집주인에게 "OO님의 친구 OO님이 들어오고 싶어해요"가 뜨고, 집주인이 허락해야 들어와요 (문이 잠겨 있어도). 거절하면 초대한 사람에게 알려 줘요.
- **👋 같은 방 사람에게 친구 신청:** 친구 창의 '🏠 같은 방에 있는 사람'이나 바탕화면 캐릭터 오른쪽 클릭 메뉴에서 바로 친구 신청해요 (데스크톱 코드 없이).

- **🏗️ 집 넓히기:** 상점 → 가구 맨 위. 1단계 5,000 · 2단계 15,000 · 3단계 30,000코인, 가로 600 → 800 → 1000 → 1200.
- **🐾 펫 교감:** 펫은 Lv.1~5. 밥을 주거나 30초마다 쓰다듬으면(집에서 펫 클릭) 경험치가 올라요. Lv.5가 되면 주인 닉네임을 부르며 "OO 안녕!" 하고 말하고, 배가 고프면 "배고파…"라고 해요 (집 · 바탕화면 모두).
- **콕 찌르기 점프:** 내 캐릭터나 친구 캐릭터를 콕 누르면 폴짝 뛰는 게 같은 방 모두에게 보여요 (집 · 바탕화면).
- **관리자:** `level 아이디 10` (캐릭터 레벨), `petlevel 아이디 P02 5 [이름]` (펫 레벨 1~5).
- **🔮 신비 물고기 10종:** 블롭피쉬 · 바다의 천사 · 크라켄 · 산갈치 · 초롱아귀 · 배럴아이 · 덤보문어 · 나뭇잎해룡 · 우파루파 · 네시. 도감에 🔮 신비 칸이 따로 있어요. 낚싯대 운은 전설과 같아서 좋은 낚싯대일수록 잘 걸려요.

## 친구

집 오른쪽 위 **👥 친구** 버튼(또는 컴퓨터 → **친구 집 놀러가기**)으로 친구 창을 열어요.

- **친구 목록**: 친구마다 상태가 보여요.
  - 🚪 **문 열림**: **놀러가기**로 바로 들어가요.
  - 🔒 **문 닫힘**: **똑똑**을 누르면 친구에게 알림이 가고, 친구가 열어 주면 들어가요.

## 캐릭터 그림 바꾸기

설정 → **내 캐릭터** → **캐릭터 그림 바꾸기**에서 그림 3장을 골라요.

- **필요한 그림**: 서 있는 그림, 앉은 그림, 걷는 그림. 배경이 투명한 PNG가 가장 예뻐요.
- **보는 방향**: 그림 속 캐릭터가 오른쪽을 보는지 왼쪽을 보는지 고르면, 걷는 방향에 맞춰 자동으로 뒤집혀요.
- **용량**: 그림은 앱이 128px PNG로 다시 그려서 올려요. 원본 파일의 다른 정보는 버려지고, 서버도 PNG가 맞는지와 크기를 한 번 더 확인해요.
- **친구 화면**: 바탕화면과 집에서 친구들에게도 내 그림으로 보여요.

배부름은 시간이 지나면 줄어요. 배가 고프면 바탕화면 고양이가 가끔 🍖를 띄워요.

### 코인

| 얻는 방법 | 코인 |
|---|---|
| 접속해 있기 | 1분마다 🪙10 (하루 최대 🪙1,000) |
| 친구와 대화 | 30초에 한 번, 채팅 1개당 🪙30 |
| 출석 체크 | 1~6일째 🪙30~100, 7일째 액세서리 |
| 낚시 | 잡은 물고기 팔기, 쓰레기 재활용 |
| 레벨 업 | 보너스 |

대화 코인은 같은 방에 다른 사람이 있을 때만 받을 수 있어요. 같은 말을 반복하면 받을 수 없어요. 코인은 전부 서버가 계산해서 앱을 조작해도 늘어나지 않아요.

## 🎣 낚시 · 📖 도감

**🎣 낚시** 탭에서 던지고, 찌가 쑥 들어가며 ❗가 뜨면 **지금 당겨!**를 눌러요. 너무 빠르거나 늦으면 놓쳐요. 하루 60번까지예요.

나오는 것은 모두 **56종**이에요. 꽝도 있어요.

| 종류 | 수 | 예시 |
|---|---|---|
| 쓰레기 | 7 | 버려진 캔, 낡은 타이어, 찢어진 장화 |
| 작은 물고기 | 16 | 금붕어, 구피, 흰동가리, 해마 |
| 중간 물고기 | 12 | 잉어, 연어, 문어, 아로와나 |
| 큰 물고기 | 21 | 참치, 범고래, 백상아리, 고래상어, 혹등고래, 대왕고래 |

- **희귀도 5단계**: 일반 · 고급 · 희귀 · 영웅 · 전설. 등급이 높을수록 잘 안 나오고 비싸요.
- **확률 공개**: 도감에서 물고기를 누르면 한 번 던질 때 나올 확률이 보여요. 전설은 다 합쳐도 0.4% 정도예요.
- **물고기 번호**: 물고기마다 `#01`~`#56` 번호가 있어요. 관리자가 이 번호로 상품처럼 줄 수 있어요.
- **도감**: 작은 · 중간 · 큰 물고기 · 쓰레기로 나뉜 책이에요. 한 쪽에 한 마리씩 크게 보이고 ◀ ▶(키보드 ← →)로 넘겨요. 아래 썸네일 줄을 누르면 그 쪽으로 바로 가요.
  - 쪽마다 번호, 그림, 이름, 희귀도, 나올 확률, 크기, 판매 가격, 내 기록(잡은 수 · 최고 크기), 들어가는 어항(작은 · 중간 · 큰 어항 · 아쿠아리움)이 나와요.
  - 못 잡은 물고기는 그림자와 ???로 보여요. 희귀도, 확률, 들어가는 곳은 미리 알 수 있어요.
  - 낚시 결과 창에서 물고기 이름을 누르면 도감의 그 쪽이 열려요.
- **자랑하기**: 영웅이나 전설을 잡으면 같은 방 사람들에게 자랑 알림이 가요.

## 🎒 가방 · 어항 · 아쿠아리움 · 교환

가방의 물고기를 누르면 이런 걸 할 수 있어요.
- **팔기**: 코인으로 바꿔요. 쓰레기는 재활용으로 🪙1을 받아요. "중복만 팔기"는 종류마다 1마리씩 남기고 팔아요.
- **어항에 풀기**: 작은 어항(3마리, 작은 물고기), 중간 어항(5마리, 작은·중간), 큰 어항(8마리, 작은·중간)이 있어요. 방에 놓은 어항을 클릭하면 물고기가 헤엄치는 걸 크게 볼 수 있어요. 어항을 가방에 넣으면 물고기는 가방으로 돌아와요.
- **아쿠아리움**: 위쪽 🐋 버튼으로 열어요. 큰 물고기(고래, 상어 등)는 여기에만 넣을 수 있고 100마리까지예요. 친구 창의 🐋로 친구 아쿠아리움도 구경할 수 있어요.
- **물고기 밥**: 🫙를 주면 물고기들이 밥을 먹고 더 활발하게 헤엄쳐요.
- **선물**: 친구에게 물고기를 보내요. 하루 5번까지예요.
- **교환**: 친구 가방을 보고 받고 싶은 물고기를 골라 신청해요. 친구가 수락하면 서로 바뀌어요. 하루 10번까지예요.

## 🎨 닉네임 색 · ✨ 운영자 효과 · 👑 집주인 왕관 (0.13)

- **닉네임 글자색**: 집 → 컴퓨터 → **설정 → 내 캐릭터**에서 닉네임 글자색을 직접 골라요(색 고르기 또는 스와치). 채팅창, 집 안 이름표, 친구 목록, 바탕화면 이름표에 모두 적용돼요.
- **운영자 전용 효과(네온 · 무지개)**: 일반 유저는 스스로 켤 수 없고, 관리자가 `node admin.js nameeffect 아이디 neon`(또는 `rainbow`)으로 줘요. 네온은 글자는 흰색이고 그 사람이 고른 닉네임 색으로 네온사인처럼 빛나요(색을 바꾸면 빛 색도 바뀌어요). 무지개는 글자색이 계속 바뀌어요. `none`으로 다시 빼요.
- **집주인 왕관 👑**: 방에 혼자 있을 땐 안 보이다가, 친구가 놀러 오거나 내가 친구 집에 놀러 가면 그 집 주인 닉네임 앞에 👑가 붙어서 누구 집인지 바로 알 수 있어요.
- **상태표시는 항상 흰색**: 이름표의 ` · 공부 중` 같은 상태 글자는 닉네임 색 · 효과와 상관없이 흰색으로 보여요.

## 🎉 시즌 이벤트: 할로윈 · 크리스마스 · 새해 (0.13)

- **관리자가 이벤트 on/off**: `node admin.js event halloween on`(끄기는 `off`)으로 할로윈 · 크리스마스(`christmas`) · 새해(`newyear`) 이벤트를 켜고 꺼요. 켜면 접속 중인 모두에게 알림이 가고, 상점에 숨겨져 있던 그 이벤트 전용 벽지 5종 · 가구 10종 · 펫 4종이 나타나요. 꺼지면 다시 숨겨지고 구매도 막혀요.
- **🎉 이벤트 상점**: 이벤트 아이템은 상점의 일반 탭에 섞이지 않고 따로 생기는 **🎉 이벤트** 탭에만 나와요. 켜진 이벤트별로 벽지 · 가구 · 펫이 나뉘어 있고, 맨 위에 켜진 이벤트의 코인 잔액과 지금까지 접속으로 번 양이 이벤트별로 보여요. 이벤트가 다 꺼지면 탭도 사라져요.
- **가격**: 이벤트 아이템은 전부 그 이벤트 코인으로 1,000 이상이에요. 가구 · 장식 1,000~2,150, 벽지 1,500~1,800, 펫 2,400~3,600 (일주일 정도 열어 두는 기준).
- **이벤트마다 다른 코인**: 할로윈은 🎃 호박 코인, 크리스마스는 🎄 트리 코인, 새해는 🧧 복주머니 코인이에요. 일반 코인(🪙, 1분마다 접속 보상)과는 완전히 별개라 서로 바꿔 쓸 수 없고, 이벤트 코인끼리도 섞이지 않아요(트리 코인으로 할로윈 아이템은 못 사요). 이벤트가 켜져 있는 동안 접속해 있으면 5분마다 켜진 이벤트의 코인을 10개씩 받아요. 두 이벤트가 같이 켜져 있으면 두 코인을 각각 받아요.
- **관리자 지급/회수**: 혹시 오류가 생기면 `node admin.js event-give 아이디 hwBat`로 이벤트 아이템을 직접 주거나 `event-take`로 빼고, `node admin.js eventcoin 아이디 halloween 50`로 그 이벤트 코인을 넣거나 `eventcoin-take`로 뺄 수 있어요.
- **모두에게 이벤트 코인**: `node admin.js eventcoin-all halloween 100 오픈 기념`처럼 쓰면 가입한 모든 사람에게 그 이벤트 코인을 한 번에 넣어요. 주기 전에 자동으로 백업하고, 접속 중인 사람은 바로 알림을 받아요.
- **이벤트 펫 레벨**: `node admin.js eventpetlevel 아이디 5`로 그 사람의 이벤트 펫 전부를, `eventpetlevel 아이디 halloween 5`로 한 이벤트 펫만 한 번에 레벨을 바꿔요(1~5). 한 마리만 바꾸려면 기존 `petlevel 아이디 P12 5 [이름]`을 써요.
- **그림**: 이벤트 벽지 15종은 무늬만이 아니라 장면(달밤 묘지, 박쥐 동굴, 눈 덮인 숲, 불꽃놀이 밤하늘, 해돋이, 한옥 등불 등)과 어울리는 바닥까지 그려져 있고, 가구 30종과 펫 12종도 명암 · 소품을 넣어 새로 찍었어요.
- **이벤트 상태 확인**: `node admin.js events`로 지금 켜진 이벤트를 볼 수 있어요. `node admin.js coins 아이디`(또는 `inv`, `list`)로 그 사람의 이벤트 코인 잔액과 접속으로 번 누적도 확인할 수 있어요.

## ✉️ 운영자에게 쪽지 (0.13)

- 집 창 위쪽 **✉️ 쪽지** 버튼으로 누구나 운영자에게 버그 제보 · 건의를 보낼 수 있어요(500자, 10분에 3개까지). 보낸 쪽지와 운영자 답장은 같은 창의 **📤 내가 보낸 쪽지**에서 보이고, 답장이 오면 팝업 알림과 빨간 점이 떠요.
- **운영자**(📢 공지 권한이 있는 사람, `writer` 명령으로 지정)에게는 **📬 받은 쪽지** 탭이 생겨요. 새 쪽지가 오면 바로 알림이 오고, 쪽지마다 답장 · 읽음 표시 · 지우기를 할 수 있어요.
- 서버 컴퓨터에서는 `node admin.js inbox`(안 읽은 쪽지, `inbox all`=전부, `inbox read`=보고 모두 읽음), `node admin.js reply 3 "답장 내용"`, `node admin.js mail-del 3`으로도 볼 수 있어요. 쪽지는 최근 300개까지 저장돼요.

## 관리자: 코인 · 물고기 · 액세서리 · 펫 넣고 빼기

서버가 켜져 있는 컴퓨터에서 새 명령 프롬프트를 열고 `desktop-pet` 폴더에서 실행해요.

```
npm run admin -- list                      전체 사용자와 코인
npm run admin -- coins 아이디              한 사람 코인 · 이벤트 코인(접속으로 번 누적 포함) 확인
npm run admin -- give 아이디 500 이벤트    코인 넣기 (메모는 선택, 받는 사람에게 알림)
npm run admin -- take 아이디 100           코인 빼기
npm run admin -- fish 아이디 23            물고기 주기 (#23 = 소라게, 개수는 뒤에: fish 아이디 23 3)
npm run admin -- fish-take 아이디 23       물고기 빼기 (개수는 뒤에)
npm run admin -- acc 아이디 A03            액세서리 주기
npm run admin -- acc-take 아이디 A03       액세서리 빼기 (쓰고 있었으면 벗겨져요)
npm run admin -- pet 아이디 P02 뽀삐       펫 주기 (이름은 선택)
npm run admin -- pet-take 아이디 P02 뽀삐  펫 빼기 (같은 종류가 여럿이면 이름으로, 없으면 가장 최근 아이)
npm run admin -- inv 아이디                가진 것 전부 보기 (코인 · 물고기 · 어항 · 아쿠아리움 · 액세서리 · 펫)
npm run admin -- fishlist                  물고기 번호표 (#01~#56 · 이름 · 등급 · 확률)
npm run admin -- acclist                   액세서리 번호표 (A01~A22)
npm run admin -- petlist                   펫 번호표 (P01~P08)
npm run admin -- notice "오늘 밤 업데이트!"  접속한 모두에게 공지
npm run admin -- backup                    지금 바로 백업
npm run admin -- backups                   백업 목록
npm run admin -- level 아이디 10           캐릭터 레벨 바꾸기 (1~99)
npm run admin -- petlevel 아이디 P02 5     펫 레벨 바꾸기 (1~5, 같은 펫이 여럿이면 이름으로)
npm run admin -- nameeffect 아이디 neon    닉네임 효과 주기 (neon · rainbow · none, 0.13)
npm run admin -- event halloween on        시즌 이벤트 켜기/끄기 (halloween · christmas · newyear, 0.13)
npm run admin -- events                    이벤트 on/off 상태 보기 (0.13)
npm run admin -- event-give 아이디 hwBat   이벤트 전용 벽지·가구·펫 주기 (event-take 로 빼기, 0.13)
npm run admin -- eventcoin 아이디 halloween 50   이벤트 코인 넣기 (halloween=🎃호박 · christmas=🎄트리 · newyear=🧧복주머니, eventcoin-take 로 빼기, 0.13)
npm run admin -- eventcoin-all halloween 100 [메모]   모든 사람에게 이벤트 코인 (자동 백업, 0.13)
npm run admin -- eventpetlevel 아이디 [이벤트] 5      이벤트 펫 레벨 한 번에 (이벤트 빼면 전부, 0.13)
npm run admin -- inbox [all|read]          ✉️ 운영자에게 온 쪽지 보기 (0.13)
npm run admin -- reply 3 "답장 내용"       쪽지 답장 (mail-del 3 으로 지우기, 0.13)
```

**자동 백업**: 서버가 하루 한 번 저장 파일을 `backups` 폴더에 복사해서 7개까지 보관해요. 되돌리려면 서버를 끄고, 원하는 백업 파일을 `buddy-data.json` 이름으로 덮어쓴 뒤 다시 켜요.

- 서버를 처음 켤 때 저장 파일 옆에 `admin.key`(관리자 비밀 키)가 만들어져요.
- 관리자 명령은 이 키가 있어야 하고, 서버와 같은 컴퓨터 안(127.0.0.1)에서만 받아요. 인터넷으로는 관리자 기능에 접근할 수 없어요.
- `admin.key`는 다른 사람에게 주지 마세요.
- 서버를 호스팅 서비스에 올렸다면, 그 서비스의 웹 터미널(셸)에서 같은 명령을 쓰면 돼요.

## 업데이트 배포하기 (자동 업데이트)

설치된 앱은 켜질 때와 6시간마다 새 버전을 확인해요.
- **Windows**: 새 버전을 몰래 받아 두었다가 다음에 껐다 켤 때 바뀌어요. 집 위쪽 띠나 트레이의 "지금 다시 시작"을 누르면 바로 바뀌어요.
- **맥**: 애플 서명이 없어서 자동 설치는 안 돼요. 새 버전이 나왔다고 알려 주고 다운로드 페이지를 열어 줘요.

### 처음 한 번만
1. GitHub에서 **New repository**를 만들어요.
   - 이름: `desktop-buddy-releases`
   - **Public** (설치 파일만 올라가요. 코드는 안 올라가요)
   - **Add a README file**에 체크
2. 내 GitHub 아이디를 두 곳에 넣어요.
   - `package.json`의 `"owner": "YOUR_GITHUB_ID"`
   - `src/defaults.json`의 `releasesUrl` 안 `YOUR_GITHUB_ID`

### 새 버전을 낼 때마다
1. `package.json`의 `"version"`을 올려요. 예: `"0.5.0"` → `"0.5.1"`
2. 설치 파일을 만들어요.
   ```
   npm run dist
   ```
3. GitHub `desktop-buddy-releases` 저장소 → 오른쪽 **Releases** → **Draft a new release**를 눌러요.
   - **Choose a tag**에 `v0.5.1`을 입력하고 **Create new tag**
   - 제목은 자유 (예: `v0.5.1 피아노 추가`)
   - `dist` 폴더의 파일 **3개**를 끌어다 놓아요.
     - `DesktopBuddy-Setup-0.5.1.exe`
     - `DesktopBuddy-Setup-0.5.1.exe.blockmap`
     - `latest.yml`
   - **Publish release**를 눌러요. Draft로 저장하면 안 돼요.
4. 끝이에요. 친구들 앱이 알아서 받아요.

친구들에게 처음 나눠 줄 때도 이 페이지 링크(`https://github.com/내아이디/desktop-buddy-releases/releases/latest`)를 보내면 돼요.

### 서버를 크게 바꿨다면
`server/catalog.js`의 `minClientVersion`을 새 버전으로 올려요. 그보다 오래된 앱은 접속하는 대신 "업데이트가 필요해요" 안내를 받고, Windows는 업데이트를 바로 받아서 설치해요.

## 서버를 인터넷에 올리기

`server` 폴더를 Render, Railway, Fly.io 같은 곳에 올려요. 시작 명령은 `npm start`이고, 반드시 아래 세 가지를 지켜 주세요.

1. **https 주소로 배포**하고, 앱에는 `wss://주소`를 넣어요. 앱은 암호화되지 않은 인터넷 서버(`ws://`)에는 비밀번호를 보내지 않아요. 같은 와이파이(192.168.x.x 등)와 내 컴퓨터는 예외예요.
2. **저장 공간을 고정**해요. 계정과 코인은 `DATA_FILE` 경로(기본 `server/data/buddy-data.json`)에 저장돼요. 무료 호스팅은 재시작하면 파일이 지워지는 경우가 많아서, 영구 디스크를 붙이고 `DATA_FILE`을 그 안으로 지정해야 해요.
3. 호스팅의 프록시 뒤에서 돌아가면 `TRUST_PROXY=1`을 설정해요. 그래야 접속 횟수 제한이 실제 사용자 IP 기준으로 동작해요.

## 보안 정리

| 항목 | 처리 방식 |
|---|---|
| 비밀번호 | 서버에 원문을 저장하지 않아요. scrypt로 해시하고, 비교할 때도 시간 차이로 정보가 새지 않게 해요 |
| 자동 로그인 | 비밀번호 대신 무작위 토큰을 써요. 앱은 운영체제 암호화 저장소(Windows DPAPI, macOS 키체인)에 보관하고, 서버는 토큰의 해시만 저장해요. 60일 미사용 시 만료, 로그아웃하면 즉시 폐기, 기기는 5대까지 |
| 계정 공격 | IP당 가입·로그인 횟수 제한, 아이디당 실패 횟수 제한. 로그인 실패 메시지로는 아이디가 있는지 알 수 없어요 |
| 동시 접속 | 같은 계정은 한 곳에서만 접속돼요. 다른 곳에서 로그인하면 이전 연결이 끊겨서 코인을 두 배로 받을 수 없어요 |
| 코드 찍어보기 | 데스크톱 코드는 8자리라 약 1조 가지예요. 틀린 코드를 10분에 10번 넘게 넣으면 막혀요 |
| 사칭 방지 | 닉네임은 겹칠 수 있지만, 고유 아이디(@아이디)가 항상 닉네임 아래에 같이 표시돼요 |
| 친구 · 문 두드리기 | 친구만 똑똑할 수 있고(15초에 한 번), 친구 신청은 대기 30개·친구 100명까지예요. 문을 열어 준 허락은 2분 뒤 사라져요 |
| 코인 선물 | 친구에게만, 하루 합계 100까지, 1분에 5번까지. 부계정으로 코인을 몰아주는 걸 막아요 |
| 관리자 지급 | 같은 컴퓨터(127.0.0.1)에서 비밀 키로만. 인터넷에 열려 있지 않아요 |
| 친구 추가 | 데스크톱 코드로만 해요. 아이디를 찍어 보며 누가 가입했는지 알아내는 걸 막아요 |
| 캐릭터 그림 | 앱이 그림을 다시 그려서 원본 파일의 숨은 정보를 버리고, 서버는 PNG 형식·크기(256px, 64KB 이하)를 확인해요 |
| 코인·가구·레벨 | 가격, 보상, 소지 개수 확인을 모두 서버가 해요 |
| 서버 부하 | IP당 연결 6개, 연결당 메시지 속도 제한, 메시지 크기 제한, 15초 안에 로그인하지 않으면 연결 끊기 |
| 앱 | 화면 코드는 운영체제 기능에 직접 접근할 수 없어요(격리 + 허용된 통로만). 외부 페이지로 이동할 수 없고, 채팅은 글자로만 표시돼서 스크립트가 실행되지 않아요 |

### 아직 남은 것

- **계정 관리**: 비밀번호 변경은 설정 → 계정에서 할 수 있지만, 비밀번호 찾기와 계정 삭제는 없어요. 이메일 인증이 필요해요.
- **차단**: 친구 목록이나 내 집 손님 목록의 🚫로 차단해요. 채팅이 안 보이고 집에 못 오고 친구에서도 빠져요. 설정 → 계정에서 풀 수 있어요. 신고 기능은 아직 없어요.
- **저장소**: 사용자가 많아지면 JSON 파일 대신 SQLite나 Postgres를 써야 해요.
- **코드 서명**: 설치 파일에 서명이 없어서 Windows나 macOS가 "확인되지 않은 앱" 경고를 띄워요. 배포하려면 서명 인증서가 필요해요.
